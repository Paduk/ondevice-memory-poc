# Appendix: Detailed Results on Human-Authored Evaluation Data

본 부록은 인간이 독립적으로 재작성하고 검수한 Human Standard Test
(HST)와 Human Challenge Test (HCT)에 대한 모델별 결과를 제시한다. HST는
20개 시나리오와 320개 Quiz, HCT는 20개 시나리오와 574개 Quiz로 구성된다.
모든 값의 단위는 퍼센트(%)이며, 각 셀은 `Composite / Quiz ESM` 순서로
표시한다. Delta-v3는 본문의 대표 설정과 동일하게 \(k=5\)를 사용하였다.

평균 Quiz ESM은 Delta-v3가 76.93으로 가장 높았다.

분석한다.

## A.3 Reporting Note

Composite는 다음과 같이 계산한다.

\[
\mathrm{Composite}
=0.60\,\mathrm{Quiz\ ESM}
+0.25\,\mathrm{Final\text{-}memory\ F1}
+0.15\,\mathrm{Update\ F1}.
\]

굵게 표시된 값은 각 모델 또는 평균 행에서 가장 높은 결과이다. 한 셀에서
Composite와 Quiz ESM의 최우수 방법이 서로 다른 경우에는 해당 값만 개별적으로
강조하였다.
